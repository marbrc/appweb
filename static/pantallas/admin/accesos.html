Códigos de acceso

Un código por clase para que solo evalúen quienes lo recibieron

Cada clase (grupo + materia + docente) tiene su propio código. El alumno abre el enlace o escribe el código y contesta sin cuenta, de forma anónima. Si regeneras o revocas un código, el anterior deja de funcionar.
